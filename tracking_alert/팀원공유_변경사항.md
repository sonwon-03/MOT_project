# tracking_alert 변경 공유 (조원용)

깃허브 올리기 전, 최근 손본 내용 요약입니다.  
대상 폴더: `tracking_alert/` (저장소: `MOT_project`)

---

## 한 줄 요약

사고 판정은 **급감속 + 그 상태 유지**만 사용합니다.  
선회 제외·근접(박스 겹침) 태그는 빼 두었고, 속도는 **박스 중심 + 크기(원근)** 로 추정합니다.

---

## 주요 기능

| 기능 | 하는 일 |
| --- | --- |
| 객체 검출·추적 | YOLO로 사람/차량 검출 → ByteTrack으로 ID 유지 |
| 사고 의심 알림 | 급감속 후 저속 유지 시 빨간 박스 + 로그 (+ 알림음) |
| 화면 캡처 모드 | 모니터/영역 실시간 추적 |
| 영상 파일 모드 | 로컬·저장 영상 분석, 결과 녹화·검토 |
| 유튜브 입력 | 임시 다운로드 / 영구 저장 후 같은 파이프라인으로 분석 |
| 가림(가려짐) 예측 | 잠깐 안 보여도 등속 예측으로 점선 박스 유지 |
| 소형·저화질 강화 | 작은/흐린 객체도 잡히도록 확대·고해상도 추론 |
| 민감도·신뢰도 조절 | 사고 민감도(0.25 단위), 검출 conf 슬라이더 |
| 성능평가 | 사고/정상 폴더로 정확도 측정 |
| 설정 저장 | `user_settings.json`에 현재 옵션 보관 |

화면 표시: 초록=일반 추적, 빨강=사고 의심, 주황 점선=가림 예측, 화살표=속도 방향.

## 핵심 요소 (파이프라인)

```text
입력(화면/영상/유튜브)
  → YOLO 검출 (+ 소형·저화질 강화)
  → ByteTrack 추적 (ID)
  → 속도·가속도 추정 (중심 이동 + 박스 크기)
  → 사고 의심 판정 (급감속 → 상태 유지)
  → UI/오버레이 표시 + 알림음 + 로그/평가
```

| 핵심 요소 | 역할 | 담당 코드 |
| --- | --- | --- |
| **검출** | 프레임에서 사람·차 박스 | `src/tracker.py` (YOLO) |
| **추적** | 프레임 간 같은 객체에 ID | `src/tracker.py` (ByteTrack) |
| **운동 추정** | 속도·가속도·원근(크기) | `src/motion.py` |
| **사고 판정** | 급감속 + 유지 → 의심 이벤트 | `src/event_detector.py` |
| **가림 유지** | 짧은 미검출 시 위치 예측 | 가림 hold (UI/설정) |
| **설정** | conf, 민감도, 토글 | `config.py`, UI 슬라이더 |
| **UI** | 모드·미리보기·알림·평가 | `ui_app.py` |
| **평가** | 사고/정상 영상 성능 | `eval_accuracy.py` |

### 사고 판정에서 켜고 끄는 두 축

| 옵션 | 의미 |
| --- | --- |
| 가속도 급변 | 속도가 크게 떨어질 때(가속도 스파이크/급락) 후보로 봄 |
| 급변 후 상태 유지 | 그 저속이 몇 프레임 유지돼야 확정 |

둘 다 켠 상태가 기본이고, 오버레이에서 F1/F2로 토글할 수 있습니다.

## 사고 판정 (현재 원리)

| 단계 | 내용 |
| --- | --- |
| 1 | 움직이던 객체의 속도가 크게 떨어짐 (`가속도 급변` 옵션과 함께 봄) |
| 2 | 그 저속이 몇 프레임 유지되면 확정 (`급변 후 상태 유지`) |
| 보조 | 감속 직후 추적이 끊겨도, 정지로 보고 확정할 수 있음 |
| 태그 | `accident_suspect` / 낙하 패턴이면 `fall_suspect` |

### 더 이상 쓰지 않는 것

- **코너 선회 제외 필터** — 선회하면서 사고(스핀아웃)인 경우를 놓칠 수 있어 제거
- **근접 충돌 태그** (`collision_suspect`, 박스 겹침) — 원근·세로 영상에서 오탐이 많아 제거
- **세로 영상 전용 분기** (`h > w`) — 판정이 부정확해서 제거

설정 파일 호환을 위해 `use_proximity_tag` 같은 필드는 남아 있을 수 있지만, **기본값 False / 실제 로직 미사용**입니다.

### 시작 직후 오탐 방지

- 트랙이 생긴 지 얼마 안 되면 판정 안 함 (`min_track_age`)
- 기준 속도 이력이 쌓이기 전엔 급감속으로 안 봄
- “달리던 차”만 대상 (`min_move_speed` 미만이면 제외)  
  → **0에서 갑자기 빨라지는 것**은 사고 후보가 아님

### 알아둘 한계

화면상 픽셀 속도 기준이라, **실제로는 일정 속도**여도

- 멀어지며 화면 이동량이 줄거나
- YOLO 박스가 흔들리거나
- 추적이 잠깐 끊기면

가끔 사고로 잡힐 수 있습니다.

## 이번에 바꾼·추가한 기능

### 검출 / 추적

| 항목 | 설명 |
| --- | --- |
| 검출 신뢰도 하한 확대 | 매우 낮은 conf까지 슬라이더로 조절 가능 (저화질·소형 객체용) |
| 소형·저화질 검출 강화 | 짧은 변 &lt; 720이면 확대 후 추론, `imgsz`≈1280 (끄면 ≈960) |
| 검출 상한 | `max_det=500`, 추적에 쓸 상위 박스 `keep_top=120` (느려짐 완화) |
| 속도 = 중심 + 크기 | 박스가 작아지면 “앞으로/멀어짐”으로 속도에 반영 (`motion.py`) |

### UI / 사용성

| 항목 | 설명 |
| --- | --- |
| 모드 | 화면 캡처 / 영상 파일 / 성능평가 |
| 유튜브 | 임시 다운로드 + 영구 저장 버튼 |
| 사고 알림음 | ON/OFF (로그·박스 표시는 유지) |
| 민감도 | 0.25 단위 (예: 1.25, 1.5 …), 기본 3 |
| 가림 유지 | 가려진 동안 등속 예측(점선), 초 단위 설정 |
| 설정 저장 | `user_settings.json` |
| 미리보기 | BGR→PPM 등으로 색 반전·끊김 이슈 완화 |

### 성능평가

- `eval_data/accident`, `eval_data/normal` 기준 정확도 측정
- UI **성능평가** 또는 `python eval_accuracy.py --data eval_data`
- 결과는 `outputs/eval_accuracy/` (영상 파일은 git에 올리지 않음)

### 오버레이 단축키 (참고)

- `F1` 가속도 급변 ON/OFF  
- `F2` 급변 후 상태 유지 ON/OFF  
- ~~`F3` 근접 태그~~ → **삭제됨**
