# 영상 저장소

여기에 mp4/avi/mov/mkv 파일을 넣으면 **영상 파일 모드** 목록에 바로 나타납니다.

추가로 `eval_data/accident`, `eval_data/normal` 영상도 같은 목록에서 선택할 수 있습니다.

## 유튜브

- 가져오기는 먼저 `video_library/youtube_temp/`에 **임시 저장**됩니다.
- 목록에는 `[임시]`로 표시되며, 자동 선택됩니다.
- 앱을 끄거나 영구 영상이 아닌 다른 영상을 고르면 임시 파일은 삭제됩니다.
- **영구 저장**을 누르면 `video_library/youtube/`로 옮겨지고 `[유튜브]`로 남습니다.
